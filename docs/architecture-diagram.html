SkillSync Architecture Diagram

Tauri v2 Native Desktop Process • React 19 WebView • Async libgit2 Engine

Declarative Presentation Layer

  • • React 19 + TypeScript: Strict static type checking with zero any-casting.
  • • Tailwind CSS v4 & shadcn/ui: Accessible primitives complying with WCAG 2.1 AA.
  • • Zustand & Immer: Sub-100ms optimistic updates and instantaneous UI feedback.
  • • TanStack Virtual: 60/120 FPS rendering across 1,000+ indexed agent skills.

Native Rust Core Performance

  • • Low Memory Footprint: 35-50 MB RAM idle vs 200+ MB in Electron alternatives.
  • • Async Concurrency: Tokio Semaphore pool regulating 3-10 parallel update tasks.
  • • libgit2 Integration: Subprocess-free Git checkout, fetch, and tag analysis.
  • • Reactive File Watcher: Inotify / FSEvents kernel alerts without CPU polling.

Atomic Safety & Zero Data Loss

  • • 7-Stage Atomic Protocol: Guaranteed pre-update snapshot compression.
  • • Sub-Second Instant Rollback: Restores prior working state on any Git conflict.
  • • Dirty Worktree Protection: Blocks updates on uncommitted local code edits.
  • • Audit Log Retention: Configurable 14 to 30 day point-in-time recovery.
