# SkillSync v1.2.2 — CLI discovery and nested repository updates

Released: 18 September 2026

## Fixed

- Claude Code updates now discover the CLI outside the desktop application's limited `PATH`, including `~/.local/bin/claude`, `~/.claude/local/claude`, Homebrew, npm-global and nvm installations.
- `SKILLSYNC_CLAUDE_CLI` can explicitly select a Claude Code executable when several installations exist.
- Nested skills now use the repository root for Git branch detection, commit comparison, checkout and safety snapshots.
- A package such as `marketingskills/skills/ab-testing` is no longer compared incorrectly against an unrelated GitHub release tag; its tracked branch and upstream commit are used instead.
- Full repository snapshots protect rollback when an installed skill lives below the repository root.

## Verification

- 50 Rust library tests passed.
- ESLint, TypeScript/Vite production build, Prettier and Rust formatting checks passed.
- Tagged CI produces signed macOS DMG and Windows MSI/EXE updater artifacts.
