# SkillSync v1.2.7 — Persistent tag-version detection

Released: 20 September 2026

## Fixed

- SkillSync now uses an exact checked-out SemVer Git tag as the authoritative installed version for all supported skill manifests: `SKILL.md`, `skill.json` and explicit skill `package.json`.
- This prevents a completed tag update from showing again after a rescan because an older version remains in nested skill metadata. For example, an installation on `v2.11.1` is reported as `2.11.1` even if its `SKILL.md` says `2.0.0`.
- When multiple SemVer tags refer to the same commit, the highest release is selected deterministically.
- Branch-tracked and non-Git resources retain manifest-based versioning; their update checks continue to compare commits or safe adapters as appropriate.

## Verification

- Added a regression that scans tagged `SKILL.md`, `skill.json`, and `package.json` skills with intentionally stale embedded versions. All three resolve to the checked-out tag.
- Rust tests, Clippy, ESLint, TypeScript/Vite build and Prettier are required before publication.

## Breaking changes

None. This is a backward-compatible patch release under Semantic Versioning.
