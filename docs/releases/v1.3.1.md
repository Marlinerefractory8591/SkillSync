# SkillSync v1.3.1 — Reliable removal and update-source tracking

Released: 23 September 2026

## Fixed

- Removing one installation now affects only that selected location. **Remove everywhere** processes each declared installation independently: a damaged manifest, inaccessible directory or failed safety snapshot at one location no longer prevents other selected copies from being removed. Any partial result lists the paths that were removed and the locations that need attention.
- Removal failures are shown inside the skill details window, where the action is performed, rather than only behind the modal.
- The tracking filter now means **No update source**, not **No local branch**. A Git remote, GitHub release source, tag or detached-HEAD checkout can be updateable without a checked-out branch and will no longer be misclassified.
- Valid MCP and plugin manifests are discovery boundaries. Their bundled examples and nested manifests are not reported as additional top-level managed items.

## Performance

- Reuse identical upstream results within one scan when multiple skills share the same remote, current version, tracking ref and item type. Each skill still receives its own status and update event.

## Verification

- 69 Rust tests passed, including selected-location removal, partial remove-everywhere failures, rejection of unknown paths, and nested plugin discovery boundaries.
- 14 frontend tests passed, including remote-backed detached HEADs, release-only sources, and missing-source classification.
- ESLint, TypeScript/Vite production build, Rust formatting and Clippy passed locally.

## Breaking changes

None. This is a backward-compatible patch release under Semantic Versioning.
