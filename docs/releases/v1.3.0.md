# SkillSync v1.3.0 — Accurate branch queue, bounded discovery and safe removal

Released: 21 September 2026

## Added

### Remove one location or all locations

Each skill, MCP integration and plugin now exposes a destructive-action flow in its detail panel:

1. select **Usuń** next to one installation path to remove only that location; or
2. select **Usuń wszędzie** to remove every listed location.

SkillSync asks for confirmation, re-discovers the resource, rejects paths not belonging to it, validates the manifest and creates a safety snapshot before removing a real directory. Directory symlinks are unlinked only; their target is never deleted. A stale card also cannot delete another independently discovered resource below the same directory.

## Fixed

- The **Bez gałęzi** count and view update immediately after saving a manual branch. A tag or detached-HEAD short SHA no longer masquerades as a branch.
- A valid skill root is now a discovery boundary. Nested documentation, examples and a bundled `skills/` subtree do not become duplicate cards. Repositories that are collections without a root manifest continue to show their real child skills.
- Symlinked installations are counted once per configured location, rather than once as the link and again as its canonical target.

## Regression coverage

- Manual branch assignment and detached-HEAD branch filtering.
- Nested manifest boundaries and manifest-free collections.
- One-location deletion, foreign-path rejection and directory-symlink safety.

## Breaking changes

None. This is a backward-compatible minor release under Semantic Versioning.
