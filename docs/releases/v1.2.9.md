# SkillSync v1.2.9 — Generated adapter checkout-conflict recovery

Released: 20 September 2026

## Fixed

Some portable CLI skills do not contain a native `SKILL.md`. SkillSync creates a small, untracked adapter so these packages remain discoverable. If a later Git tag or branch adds an upstream `SKILL.md`, Git correctly refuses a safe checkout because it would overwrite that local adapter and reports a checkout conflict.

Before a Git checkout, SkillSync now:

1. creates the normal atomic safety snapshot;
2. checks every location affected by the Git worktree;
3. removes only an **untracked** `SKILL.md` with both the `generated-by: SkillSync` marker and the exact SkillSync adapter text;
4. performs the checkout and verifies the upstream manifest in every declared location.

User-authored manifests and upstream-tracked manifests are not removed. Any later failure restores the complete snapshot.

## Regression coverage

- A portable package update that creates an adapter, followed by a newer tag that restores a real `SKILL.md`, completes without a Git checkout conflict.
- A user-owned `SKILL.md` is preserved by the cleanup guard.

## Breaking changes

None. This is a backward-compatible patch release under Semantic Versioning.
